## 🚀 How to Upload to GitHub & Connect to Shopify

### Step 1: Initialize Git and Push to GitHub
1. Open your terminal in this theme directory:
   ```bash
   cd "/Users/kmall.pk/Library/CloudStorage/GoogleDrive-rizwansaeed610@gmail.com/My Drive/data themes shopify "
   ```
2. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - ShinnySkin OS 2.0 Theme"
   git branch -M main
   ```
3. Create a new repository on your GitHub account (e.g. `shinnyskin-shopify-theme`).
4. Link and push to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/shinnyskin-shopify-theme.git
   git push -u origin main
   ```

---

### Step 2: Connect GitHub Directly to Shopify Store
1. Log in to your **Shopify Admin** (`admin.shopify.com`).
2. Go to **Online Store** > **Themes**.
3. Under the **Theme library** section, click **Add theme** > **Connect from GitHub**.
4. Log in with your GitHub account and authorize Shopify.
5. Select your repository: `shinnyskin-shopify-theme` and choose the `main` branch.
6. Click **Connect theme**.
7. Shopify will automatically pull all theme files, sections, blocks, templates, and settings! Any future commits to your `main` branch will automatically sync with Shopify in real time.
